# 自行循环学习流程

## 核心理念

> https://anime.map987.dpdns.org/ 域名绑定好了，后续我们每次开发都可以通过这个域名自行的查看，自行的迭代了，自行的监督。实现一个自行循环学习的流程。

## 说明

- **固定访问入口**：`https://anime.map987.dpdns.org/` 作为本项目（Animaku EdgeOne 版）的线上地址。
- **自行查看**：每次改动部署后，通过这个域名直接看到真实线上的效果，而不是只靠本地推理或读代码。
- **自行迭代**：发现问题 → 改代码 → push → CI 自动构建回写 → webhook 通知 EdgeOne 部署 → 再通过该域名验证，形成闭环。
- **自行监督**：线上页面本身成为反馈源，可持续观察、验证、纠偏。

## 闭环链路（与 CI 机制配合）

```
改代码 / 上游更新
   → push 到 kfc50/animaku-edgeone
   → CNB CI：submodule update --remote → build-edge.mjs → sync-web → inject
   → ci-commit-artifacts.sh 回写产物（无变化则停，防循环）
   → webhook 通知 EdgeOne
   → EdgeOne 拉仓库部署
   → 访问 https://anime.map987.dpdns.org/ 自行查看 / 迭代 / 监督
   → 发现问题回到起点
```
